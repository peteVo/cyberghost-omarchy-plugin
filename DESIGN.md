# Native Omarchy VPN panel

Operate mode for a 13-inch ThinkPad. Preserve the installed Omarchy visual world: `Ui.BarIconButton`, `Ui.Panel`, `Ui.KeyboardPanel`, `Ui.PanelHero`, native buttons, searchable dropdowns, text field, section labels and separators. A 360-unit panel fits to the available screen and scrolls above 550 units. Qt controls own text editing and Tab navigation; Escape closes, and focused controls scroll into view.

Typography uses `Style.font`; spacing, borders, focus, hover and animation come from the shell's controls and tokens. Text uses the popup theme palette in both light and dark themes. CyberGhost yellow is limited to the connected CG mark. All external content is plain text. Connection state, selected next location and last public-IP lookup are separate concepts.

The main action stays disabled until a backend can confirm an actionable state. Loading, unknown, dependency, profile, authorization, location-empty and retry states are explicit. Country/city search uses native controls and exposes only discovered options. The official backend includes protocol/server selection, favorites and location switching. Favorites persist locally; backend/profile choices last for the shell session unless configured in the bar entry. Connection metadata is labeled as requested or client-reported, never as independently verified endpoint identity. Security and automatic reconnect features are not presented as working controls.

Source/API and accessibility paths were reviewed using Impeccable. The panel rendered in the existing Omarchy shell at 1920×1080 and 150% scaling. The bounded correction grouped Locations, Details and Settings and kept current connection information above the actions. Keyboard checks covered search/selection, protocol, favorites, connect/switch/disconnect, IP lookup and Escape/reopen. Favorites survived a native restart; a cold-start stale-backend response was fixed. The installed shell retained cached QML on hot reload, so final source changes were loaded with native restarts while unlocked. Mouse input and a light-theme render have not been tested. Qt lint has dynamic-property and JavaScript-style warnings; it is not visual evidence. The independent Impeccable finish review returned `ship` with no material fixes after inspecting the final native captures.
