# CyberGhost for Omarchy

Audience: a CyberGhost subscriber on Arch/Omarchy 4 using Hyprland, Quickshell, NetworkManager and a 13-inch ThinkPad.

Core task: connect to a CyberGhost country or city without repeated manual downloads **where an authorized provider interface exists**. If none is verified on Arch, provide a transparent fallback without presenting it as full dynamic functionality.

Invariants: no embedded provider app keys; no bypass of account authentication; no privilege escalation through user-writable helpers; no claiming network security from a connection label. Design mode: Operate, native Omarchy.
